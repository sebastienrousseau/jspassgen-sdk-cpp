# AGENTS.md

`jspassgen-sdk-cpp` is the native C++17 port of the jspassgen
core (`packages/core` in
[jspassgen](https://github.com/sebastienrousseau/jspassgen)). jspassgen
is a suite of repositories released at one version
([ADR 0001 in jspassgen](https://github.com/sebastienrousseau/jspassgen/blob/main/docs/adr/0001-ecosystem-lockstep.md)).
This repository's value is that a C++ caller gets exactly the passwords
the core would make from the same random draws, generated on the
caller's machine from the operating system's CSPRNG and never sent
anywhere. Today it holds the random port and its OS backends only; the
generators wait for the conformance kit (shipped in jspassgen 0.0.21)
to be vendored. Read
[CONTRIBUTING.md](CONTRIBUTING.md) as well.

## Rules

- **Version.** `0.0.x`, moving by exactly `0.0.1`, in lockstep with the
  jspassgen suite. Never propose a `0.1.0` or `1.0` jump, and never bump
  it as a side effect. The single source of truth is
  `project(... VERSION)` in `CMakeLists.txt`; when it moves, every file
  `scripts/verify-release-versions` lists moves with it (`CITATION.cff`,
  the SECURITY and SUPPORT tables, the README and manual install
  snippets, the bug template and `tests/package/`), and `CHANGELOG.md`
  gets the new heading. Work for the next version starts on
  `feat/v<next-version>`.
- **No generator before the kit.** Do not port a password type,
  validation rule, entropy calculation or wordlist until jspassgen's
  conformance kit is vendored here; a port written without it cannot be
  shown to match the core. The kit ships in jspassgen 0.0.21; `conformance/` is vendored
  byte for byte from jspassgen with the commit in `ci/core.ref`, and is
  never edited here.
- **Randomness from the OS CSPRNG only.** Every draw goes through
  `RandomSource`. Never add a user-space generator, a seedable fallback,
  `std::random_device`, `rand()` or `<random>` engines to library code,
  and never return a modulo of raw bytes unchecked: `random_int` uses
  rejection sampling. An unknown platform fails to compile.
- **Local only.** No network call, no telemetry, no logging, no file
  writes. Never put generated bytes or secrets in an exception message.
- **Complexity.** Per function: cyclomatic 10, cognitive 15, Halstead
  difficulty 30, 60 lines (`make complexity`, and clang-tidy); 500 lines
  per file. No new suppressions; `scripts/complexity-baseline.json` only
  shrinks.
- **Warnings are errors.** `-Wall -Wextra -Wpedantic -Wconversion
  -Wshadow -Werror` and MSVC `/W4 /WX`; fix the cause rather than adding
  `NOLINT` or a pragma.
- **Commits.** Conventional, subject at most 50 characters, body wrapped
  at 72, signed off (`git commit -s`), SSH-signed, with an
  `Assisted-by:` trailer for agent work. Never rewrite pushed history.
- **Facts.** Never claim a feature, a benchmark number, a platform or a
  registry that the repository does not prove.

## The gate

```sh
make check          # the local gate
make package-test   # the installed CMake package
```

DEVELOPMENT.md maps every CI job to its local command.

## Leave alone

`LICENSE*`, `LICENSES/`, `DCO.txt`, `KEYS.asc`, and the pinned
GoogleTest hash in `tests/CMakeLists.txt` unless the task is to update
it (then verify the new hash against the downloaded archive). Generated
output (`build*/`) is never committed.
